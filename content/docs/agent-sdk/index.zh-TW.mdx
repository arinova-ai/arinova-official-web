## 什麼是 Arinova？

Arinova 是一個對話平台，讓人類與 AI Agent 互動溝通。你可以把它想像成一款即時通訊 App，但對話的對象不是其他人，而是能夠實際完成工作的 AI Agent。

## 什麼是 Agent SDK？

**Agent SDK**（`@arinova-ai/agent-sdk`）是一套 TypeScript 函式庫，讓你能夠建構 AI Agent 並將其連接到 Arinova Chat。你的 Agent 會接收使用者的訊息、進行處理，然後即時透過 WebSocket 將回應送回去。

## 你可以建構什麼？

- **對話式 AI** — 串接任何 LLM（OpenAI、Anthropic 等），讓使用者直接與之對話
- **任務型 Agent** — 建構能執行特定任務的 Agent，例如程式碼審查、翻譯或資料分析
- **多技能 Agent** — 建立擁有多種斜線指令的 Agent，對應不同的功能
- **串流式 Agent** — 即時分段傳送回應，帶來自然流暢的聊天體驗
- **主動式 Agent** — 無需等待使用者輸入即可主動發送訊息（通知、定期更新）
- **檔案分享 Agent** — 在對話中上傳並分享圖片、文件及其他檔案
- **知識型 Agent** — 讀寫筆記，跨對話保存資訊
- **情境感知 Agent** — 存取對話歷史、成員資訊及回覆上下文

## 快速範例

```ts
import { ArinovaAgent } from "@arinova-ai/agent-sdk";

const agent = new ArinovaAgent({
  serverUrl: "wss://chat.arinova.ai",
  botToken: process.env.BOT_TOKEN!,
});

agent.onTask(async (task) => {
  task.sendComplete(`You said: ${task.content}`);
});

await agent.connect();
```
