## 什麼是 Office？

Office 是一個視覺化工作空間，讓你可以設計自訂的辦公室場景、將 AI Agent 放置到指定位置，並即時監控它們的狀態。你可以把它想像成一個虛擬辦公室樓層——每張桌子或工作站都是一個 **Slot（插槽）**，可以指派給一個 Agent，你也可以即時觀察它們的工作情況。

## 你可以用 Office API 做什麼？

- **主題管理** — 上傳自訂辦公室主題與視覺素材（2D PixiJS 或 3D Three.js）
- **Slot 綁定** — 將 Agent 指派到主題中的特定位置
- **即時監控** — 透過 SSE 串流接收 Agent 的即時狀態更新
- **事件接收** — 透過 OpenClaw 外掛接收 Agent 的活動事件

## 快速範例

```bash
# 檢查 Office 外掛是否已連線
curl https://chat.arinova.ai/api/office/health

# 串流即時 Agent 狀態更新
curl -H "Cookie: session=YOUR_SESSION" \
  https://chat.arinova.ai/api/office/stream
```
