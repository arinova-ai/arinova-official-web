## 社群（Communities）

**社群**是 Spaces 中的基礎實體。每個社群都有一個類型來決定其行為：

| 類型 | 用途 | 主要功能 |
|---|---|---|
| `official` | 品牌 / 創作者帳號 | AI + 真人客服、認證 |
| `club` | 開放式社群群組 | 群組聊天、內建 AI 代理 |
| `lounge` | 聲音複製空間 | 語音聊天、訂閱制、用量追蹤 |

社群支援：
- **加入/離開** 可設定費用（加入費 + 月費訂閱）
- **代理整合** — 新增 AI 代理清單，供成員互動
- **成員管理** — 建立者、管理員、客服專員和一般成員

### 計費模式

- **加入費**：一次性入場費用。建立者獲得 70%。
- **月費**：定期訂閱。若有設定，會員資格在 30 天後到期。
- **代理互動費**：每次 AI 代理聊天的費用。建立者獲得 70%。

## 官方客服（Official）

官方社群提供結構化的客服系統，有三種模式：

| 客服模式 | 行為 |
|---|---|
| `ai_only` | 所有對話由 AI 處理 |
| `human_only` | 所有對話以 `waiting_human` 狀態開始 |
| `hybrid` | AI 先處理，使用者可請求轉接真人 |

### 對話生命週期

```
使用者開始聊天
    │
    ├── ai_only ──→ [ai_active] ──→ [resolved]
    │
    ├── human_only ──→ [waiting_human] ──→ [human_active] ──→ [resolved]
    │
    └── hybrid ──→ [ai_active] ──→ 轉接 ──→ [waiting_human]
                                                    │
                                                    ├──→ [human_active] ──→ [resolved]
                                                    └──→ [resolved]
```

主要角色：
- **建立者 / 管理員** — 可檢視客服佇列、接受轉接、邀請客服專員
- **客服專員** — 由建立者/管理員邀請，可接受轉接並結案對話
- **使用者** — 可開始聊天、請求轉接真人、自行結案對話

### 認證

官方社群可以提交認證申請，附上商業文件。管理員審核後批准或駁回。通過的社群會標示為已認證。

## Club

Club 是開放式社群群組，提供輕鬆的互動。成員可以：

- 在群組聊天中發送文字訊息
- 透過 `agent-chat` 與社群中的 AI 代理對話（SSE 串流）
- 使用游標式分頁瀏覽訊息歷史

代理聊天透過 SSE 即時串流回應，事件類型包含：`meta`、`chunk`、`done`、`audio_ready` 和 `error`。

## Lounge

Lounge 是以語音互動為核心的訂閱制空間：

- **聲音複製** — 創作者上傳語音樣本用於 AI 語音合成
- **免費額度** — 可設定每日免費分鐘數（預設：5 分鐘）
- **訂閱** — 以美分計價的月費，提供無限存取
- **儀表板** — 創作者可查看成員數、有效訂閱、對話數和使用統計

在 Lounge 中開始聊天會自動將使用者加入為社群成員。

## Spaces（Playgrounds）

**Spaces** 是可自訂的 Playground 環境，能透過 iframe 嵌入外部內容，並主持即時協作工作階段。

- **定義** — 每個空間有一個 JSON `definition` 欄位（可包含 `iframeUrl` 用於嵌入內容）
- **工作階段** — 即時房間，參與者可加入、互動和離開
- **參與者** — 每個工作階段追蹤已連線的參與者，可附加代理/角色/控制模式等中繼資料
- **可見性** — 空間可以是公開或私有的，可選擇性設定分類和標籤

### 工作階段生命週期

```
建立者建立工作階段
    │
    ├── 建立者自動加入為第一位參與者
    │
    ├── 其他人透過 POST .../join 加入
    │     ├── 建立新的參與者
    │     └── 或重新連線已有的參與者
    │
    └── 參與者透過 POST .../leave 離開
          └── 標記為已中斷連線（不會刪除）
```
